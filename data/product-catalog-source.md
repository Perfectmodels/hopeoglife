# Informations à enregistrer pour chaque produit

Chaque fiche produit doit contenir :

* nom du produit ;
* catégorie ;
* sous-catégorie ;
* image ;
* description ;
* code-barres ;
* référence interne ;
* unité de vente ;
* unité de stock ;
* prix d’achat ;
* prix de vente ;
* prix promotionnel ;
* quantité disponible ;
* stock minimum ;
* fournisseur ;
* emplacement ;
* taxe applicable ;
* produit actif ou inactif ;
* produit vendable ou ingrédient ;
* destination : bar, cuisine ou lounge ;
* temps de préparation ;
* accompagnements disponibles ;
* suppléments disponibles ;
* date d’expiration, si nécessaire.

Cette base peut être adaptée selon le menu réel, les marques disponibles et le positionnement du restaurant.
